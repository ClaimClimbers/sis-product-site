Glossary

Record terms, in plain English.

Disability files use short names that sound like a foreign language. This page explains the words in everyday English. It is a glossary, not a diagnosis. We do not invent findings. A Security in Social review is a read of your records. It is not a letter and not a consultative exam.

Medical record review (what Security in Social sells)

A plain-English read of the medical file you already have. What the records show. What is still missing. Clear next step. Lifetime review $395, or the yearly app at $129.99. We say no if the records are not enough. We never invent a diagnosis. We do not sell doctor letters on this site.

Medical source statement (MSS)

A written opinion from a doctor about what you can still do. It is a name you may see on a disability file. We explain the term. We do not sell or complete MSS letters on this site.

Residual functional capacity (RFC)

A way the file describes physical work limits (such as sitting, standing, walking, lifting) when the records support those details. We explain the term. We do not sell or complete RFC documents on this site.

Medical residual functional capacity (MRFC)

A way the file describes mental work limits for a disability claim. We explain the term. We do not sell or complete MRFC documents on this site.

Consultative exam

An exam arranged in the disability process, separate from a private record review. Security in Social does not provide consultative exams. Our product is a read of records you already have (and an optional app for questions), not an exam appointment.

File gap / not enough records

Parts of the story the medical file does not yet support. A gap list names those holes in plain words. If the file is too thin, we say no. That is honesty, not a failed sale.

If you want the file read in plain English, see the medical record review.

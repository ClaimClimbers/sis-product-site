Care first, then the file

You are carrying someone else’s records.

That is a real job. Start with a medical record review. Doctor letters about work limits come later. This is not legal advice, not a promise, and not a stand-in for a representative if one already exists.

What to gather

Dated medical records that belong to the person applying. Visit notes, imaging, therapy notes, medication lists when they exist. SAMPLE details only on this public site. Do not paste live records into this demo. Production packets wait on a privacy policy.

What the review finds

We name what the file supports and what it still lacks, in writing. You get a plain-language next step. We do not file the SSDI claim.

Letters come later

Doctor-signed work-limits letters (MSS, physical RFC, mental MRFC) are on the waitlist. When they ship, specialists draft and a licensed MD or DO reviews and signs, edits, or refuses. You are not the doctor.

What families send

  • The Social Security step they are on, and a request for a records review.
  • Medical records (upload only in the beachhead).
  • Context the review should see. No invented facts.

What families get back

  • Gap report and record list.
  • A plain-language next step, or a clear written decline.
  • Doctor-signed PDF later, when letters ship and release is allowed.

Honesty is care

If the records cannot support the path, we decline. That protects the person you are helping. A letter the file cannot carry is not kindness. SAMPLE language only on these pages.
